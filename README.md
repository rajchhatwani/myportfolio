# Personal Website

Welcome to my [personal website](https://rajchhatwani.github.io/myportfolio)! This is an [MIT licensed](https://github.com/mldangelo/personal-site/blob/main/LICENSE) React-based Jamstack application. It offers a simple interface, easy modifications, static export capabilities, and free automatic deployments via [GitHub Pages](https://pages.github.com/).

It is built with React, React-Router, gh-pages for Static-Export, and GitHub Pages.
